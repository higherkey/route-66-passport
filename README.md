# Route 66 Digital Passport

> A centennial digital passport for exploring Route 66 — "The Mother Road."

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=flat-square)](https://higherkey.github.io/route-66-passport/)

## Quickstart

### Prerequisites
- Node.js 18+
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

## Project Structure
- `/app`: Next.js App Router pages and layouts.
- `/components`: Reusable UI components (Stamps, Grid, etc.).
- `/hooks`: Custom React hooks (Geolocation, LocalStorage).
- `/public`: Static assets and PWA manifest.

For a detailed technical overview and roadmap, see [PROJECT.md](./PROJECT.md).
